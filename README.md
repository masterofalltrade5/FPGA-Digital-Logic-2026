# FPGA-Digital-Logic-2026
A collection of FPGA development projects focusing on digital logic design. While these projects are academically structured as **VHDL-required curriculum labs**, I have taken the **personal initiative to independently implement each design in Verilog as well** to build fluency in both industry-standard Hardware Description Languages.

Each project directory contains a complete, dual-language implementation optimized for clean peer review, verification, and hardware synthesis.
